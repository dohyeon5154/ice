## 1. 문제 정의 (Problem Statement)

### 1.1 현재 존재하는 문제

시설재배 온실은 고온다습·밀식 환경으로 병해 확산 속도가 노지 대비 빠르다. (가정) 잿빛곰팡이병의 경우 야간 결로가 6시간 이상 지속되면 3~5일 내 인접 열로 확산되며, 발견 시점이 3일 늦어질 때마다 방제 면적이 약 2~3배 증가한다.

- **발견 지연:** 병징은 하위엽·잎 뒷면에서 먼저 발현되나, 관행 예찰은 통로에서 상위엽 위주로 이루어져 실제 인지까지 평균 3~7일이 소요된다. (가정)
- **인력 문제:** 2,000평 규모 온실을 육안 전수 예찰하려면 1일 2~3시간이 필요하나, 농가 고령화와 인건비 상승으로 전담 예찰이 사실상 불가능하다.
- **손실 규모:** (가정) 병해로 인한 폐기·상품성 저하 손실률은 연 매출 대비 약 8% 수준(연 2,800만 원).
- **과잉 방제:** 발생 여부와 무관하게 7~10일 주기 관행 살포가 이루어져 약제비가 과다 지출되고, 약제 저항성과 잔류농약 리스크가 누적된다.

### 1.2 기존 방식의 한계

| 기존 방식 | 한계 |
|---|---|
| 육안 예찰 | 작업자 숙련도에 따라 판정 편차가 크고, 초기 병반(직경 2~5mm) 인지가 어렵다. 기록이 남지 않아 확산 추이 분석이 불가능하다. |
| 캘린더식 관행 방제 | 발병 여부와 무관한 전면 살포로 약제비·노동력이 낭비되고, 동일 계열 약제 반복 사용으로 저항성이 유발된다. |
| 환경센서 기반 발병 예측 모델 (온습도·결로시간) | "발병 위험도"만 추정할 뿐, 실제 감염 개체와 위치를 특정할 수 없어 국소 방제로 연결되지 않는다. |
| 실험실 정밀 진단 (PCR/ELISA) | 정확도는 높으나 시료 채취→결과 회신까지 1~3일이 걸리고 건당 비용이 발생해 상시 예찰 수단으로 부적합하다. |
| 단순 영상 임계값 처리 (HSV 색상 필터) | 병반과 생리장해(질소 결핍, 광해, 자연 노화)의 색상 분포가 중첩되어 오탐이 다발한다. 조도 변화에 취약하다. |

### 1.3 제품이 해결하려는 핵심 가치

1. **조기 발견:** 육안 예찰 대비 평균 3일 이상 빠른 병징 감지로 확산 초기 단계에서 차단한다.
2. **국소 정밀 방제:** 감염 구역(Zone) 단위로만 방제 장치를 작동시켜 약제 사용량을 30% 이상 절감한다.
3. **판정의 표준화·기록화:** 병해 진단 근거(이미지 + Grad-CAM)와 방제 이력을 자동 축적하여 GAP 인증 및 약제 사용 대장을 자동 생성한다.
4. **무인화:** 야간·주말을 포함한 24시간 상시 예찰로 예찰 전담 인력 의존도를 제거한다.

### 1.4 왜 AI가 필요한가

- **규칙 기반 분리 불가:** 병반의 색·형태는 품종, 생육 단계, 광량, 시비 상태에 따라 크게 변동한다. 잿빛곰팡이 초기 병반과 저온 생리장해 반점은 RGB 색공간에서 분포가 겹쳐 임계값 규칙으로 구분되지 않는다.
- **다중 클래스 분류 필요성:** 병해별로 사용 약제와 방제 방식이 다르다(살균제 계열, 환기 제어, 매개충 방제 등). "이상/정상" 이진 판정만으로는 자동 방제 명령을 생성할 수 없으므로, 병해 종(種) 단위 분류가 필수다.
- **비정형 촬영 환경:** 잎 겹침, 그림자, 이슬 반사, 잎 뒤집힘 등 변형 요인이 많아 사전 정의 불가능한 패턴 학습이 요구된다.
- **결정 근거의 결합:** 이미지 신뢰도 단독으로는 오탐 억제가 어렵다. 최근 24시간 습도·결로 시간 등 환경 데이터를 결합한 확률 보정이 필요하며, 이는 학습 기반 모델에서 자연스럽게 처리된다.

## 2. 사용자 시나리오 (User Scenario)

**페르소나 (가정):** 김O철(52세), 시설 토마토 10동 재배 농장주. 스마트팜 복합환경제어기 사용 경험 있음. 상시 근로자 2명. 스마트폰 사용은 가능하나 PC 대시보드 사용 빈도는 낮음.

### 1단계 — 사용자가 제품을 설치한다

- 1동(660㎡)당 **고정형 카메라 유닛 6대**를 작물 열 상단 1.8m 높이, 하향 30° 각도로 설치한다. 1대당 촬영 커버리지는 작물 열 방향 약 4m 구간(= 1 Zone)이다.
- 동별로 **Edge 게이트웨이 1대**를 배전반 인근에 설치하고, 카메라는 PoE 이더넷으로 연결한다.
- 기존 방제 배관에 **구역별 전동 밸브 6개**를 설치하고 RS-485(Modbus RTU)로 제어 모듈에 연결한다.
- 설치자는 카메라 QR 코드를 모바일로 스캔해 기기를 등록하고, 대시보드에서 카메라–Zone–밸브를 매핑한다.
- 초기 캘리브레이션: 컬러 체커 차트를 촬영해 화이트밸런스를 보정하고, 작물 열 ROI(관심영역) 마스크를 설정한다.
- **소요:** 2인 기준 동당 약 4시간, 10동 기준 5일. (가정)

### 2단계 — AI가 데이터를 수집한다

- 촬영 주기: 주간 06:00~19:00, **10분 간격**. 카메라 60대 × 78회/일 = **일 4,680장**.
- 촬영 사양: 12MP(4032×3024) RGB, 보조 광원 5000K / CRI 90 이상 LED 스트로브 동기 발광(외광 변동 상쇄).
- 동시 수집 센서 데이터: 기온·상대습도(1분), 엽온(적외선), 조도, CO₂ → 결로 지속시간 파생 변수 계산.
- Edge 단 전처리 필터: 라플라시안 분산 기반 블러 판정, 저조도 판정, 잎 미검출 프레임 폐기 → 유효 프레임만 추론 큐로 전달(약 15% 폐기 예상).

### 3단계 — AI가 분석을 수행한다

2단계 파이프라인으로 Edge 디바이스에서 온디바이스 추론한다.

| 단계 | 모델 | 처리 내용 |
|---|---|---|
| Stage 1 — 검출 | YOLOv8n (TensorRT INT8) | 프레임 내 개별 잎 인스턴스 검출 + 병반 후보 ROI 추출. 640×640 입력. |
| Stage 2 — 분류 | EfficientNet-B0 | 검출된 ROI를 224×224로 크롭하여 7클래스 분류 + Softmax 신뢰도 산출. |
| Stage 3 — 보정 | 룰 기반 후처리 | 최근 24시간 결로시간·평균습도·엽온 기반 병해별 발병 가중치를 적용해 신뢰도를 ±0.1 범위에서 보정. 단일 프레임 판정이 아닌 **연속 3프레임(30분) 중 2회 이상 동일 클래스 검출 시에만 확정** → 순간 오탐 억제. |

- 처리 시간: 프레임당 1.5초 이내(Stage 1+2 합산).
- 원본 이미지는 Edge에 7일 보관, 판정 발생 프레임과 일 1회 샘플링 이미지만 서버로 업로드(대역폭 절감).

### 4단계 — 판단 결과를 생성한다

판정 레코드 구조: `{timestamp, house_id, zone_id, disease_class, confidence, infected_leaf_ratio, bbox[], image_url, gradcam_url, env_snapshot}`

**발병엽률(infected_leaf_ratio)** = 해당 Zone 내 병해 판정 잎 수 / 검출 총 잎 수

| 등급 | 발동 조건 | 시스템 동작 |
|---|---|---|
| **관찰 (Watch)** | 신뢰도 0.60~0.75 또는 발병엽률 < 1% | 대시보드 기록만. 알림 없음. 24시간 집중 모니터링 모드로 촬영 주기를 5분으로 단축 |
| **경보 (Alert)** | 신뢰도 ≥ 0.75 **and** 발병엽률 1~5% | 관리자 푸시·알림톡 발송 + **방제 승인 요청** (자동 살포 대기) |
| **긴급 (Critical)** | 신뢰도 ≥ 0.85 **or** 발병엽률 > 5% **or** 2개 이상 인접 Zone 동시 검출 | 안전 인터록 통과 시 **자동 방제 즉시 실행** + 관리자 알림(푸시·알림톡·SMS 동시) |

### 5단계 — 제품이 사용자 또는 주변 장치를 제어한다

- **제어 대상:** 해당 Zone의 미스트 방제 밸브(Modbus RTU 코일 ON), 약액 정량 펌프, 환기창·유동팬(습도 저감 목적, 병해별 선택 적용).
- **살포 시간 산출:** 병해 종별 표준 약량 × Zone 면적 × 발병엽률 계수 → 밸브 개방 시간(초) 계산. 1회 최대 개방 시간 180초로 상한 제한.
- **안전 인터록 (모두 통과해야 자동 실행):**
  1. 해당 동 작업자 재실 감지 없음 (출입 태그 + PIR 센서, 재실 시 무조건 차단)
  2. 직전 동일 약제 살포 후 최소 간격(안전사용기준) 경과
  3. 약액 탱크 잔량 ≥ 필요량, 배관 압력 정상 범위
  4. 일사량 임계값 이하 (약해 방지, 고광량 시 살포 지연 예약)
  5. 밸브 상태 피드백 정상 (개방 명령 후 3초 내 유량 미감지 시 즉시 중단 + 설비 이상 알림)
- 인터록 실패 또는 '경보' 등급인 경우 **자동 실행하지 않고 승인 대기 상태**로 전환, 관리자 앱에서 원터치 승인 시 실행한다. 승인 무응답 6시간 경과 시 알림을 재발송한다.
- 모든 제어 명령과 실행 결과는 감사 로그(Audit Log)에 기록한다.

### 6단계 — 사용자가 결과를 확인하고 후속 행동을 수행한다

- 관리자는 알림톡의 링크로 진입해 **원본 이미지 + Grad-CAM 히트맵 + 판정 근거(환경 조건)** 를 확인한다.
- **피드백 라벨링:** 판정에 대해 "정확 / 오탐 / 다른 병해" 3버튼으로 응답한다. 이 피드백은 재학습 데이터셋으로 축적되며, 월 1회 모델 재학습에 반영된다.
- 방제 실행 이력, 약제명, 사용량이 자동으로 **약제 사용 대장(GAP 인증 양식)** 에 기록되고 PDF로 내보내기 가능하다.
- 주간 리포트: 동별 병해 발생 추이, 확산 히트맵, 약제 사용량, 전주 대비 변화를 자동 발송한다.
- 반복 발생 Zone에 대해서는 환경 개선 권고(환기 시간 조정, 밀식도 조정)를 제안한다.

## 3. 성공 지표 (Success Metrics)

### 3.1 AI 성능 지표

| 지표 | 정의 | 목표 | 측정 방법 |
|---|---|---|---|
| 병해 분류 정확도 | 7클래스 macro F1-score | **≥ 0.90** | 홀드아웃 테스트셋 6,000장 (클래스별 최소 500장), 학습에 미사용 |
| 미탐률 (FN Rate) | 실제 병해를 정상으로 판정한 비율 | **≤ 3%** | 미탐이 손실로 직결되므로 오탐보다 엄격 관리 |
| 오탐률 (FP Rate) | 정상 잎을 병해로 판정한 비율 | **≤ 5%** | 3프레임 연속 검증 후처리 적용 기준 |
| 생리장해 구분 정확도 | 질소결핍·광해·노화 대비 병해 구분 정확도 | **≥ 0.88** | 별도 혼동 케이스셋 1,000장 |
| 조기 검출 리드타임 | 육안 예찰 확인 시점 − 시스템 최초 검출 시점 | **평균 3일 이상 선행** | 파일럿 농가 3개소 6개월 병행 검증 |

### 3.2 시스템 성능 지표

| 지표 | 목표 | 비고 |
|---|---|---|
| Edge 추론 지연 (프레임당) | ≤ 1.5초 | Stage 1+2 합산, Jetson Orin Nano 기준 |
| 검출 → 제어 명령 전달 지연 | ≤ 5초 | 긴급 등급 기준, Edge 내부 처리 |
| 검출 → 관리자 알림 도달 | ≤ 30초 | 서버 경유, 네트워크 정상 시 |
| 이미지 수집 성공률 | ≥ 98% | 월간, 계획 촬영 대비 유효 프레임 |
| 시스템 가동률 (Uptime) | ≥ 99.0% | 월간, 계획 정비 시간 제외 |

## 5. 개발 범위 / 비범위 (Scope)

### 5.1 개발 범위 (In Scope) — v1.0

1. **실시간 잎 검출 및 병해 분류** — YOLOv8n + EfficientNet-B0 2단계 파이프라인, 토마토 7클래스 온디바이스 추론
2. **발병엽률 산출 및 3단계 등급 판정 로직** — 연속 프레임 검증, 환경 데이터 기반 신뢰도 보정 후처리 포함
3. **방제 장치 자동 제어** — Modbus RTU 기반 Zone별 전동밸브·정량펌프 제어, 살포 시간 자동 산출
4. **안전 인터록 모듈** — 작업자 재실 감지, 약제 안전사용 간격 검증, 유량 피드백 기반 이상 시 자동 중단
5. **알림 시스템** — 등급별 FCM 푸시 / 카카오 알림톡 / SMS 다채널 발송, 승인 대기 및 재알림 로직
6. **데이터 수집·저장 파이프라인** — 이미지 S3 업로드, 센서 시계열 TimescaleDB 적재, 7일 Edge 로컬 버퍼링
7. **관리자 웹 대시보드** — 동/Zone별 병해 현황 맵, 판정 이력 조회, 원본 이미지 + Grad-CAM 뷰어, 방제 이력, 주간 리포트
8. **감사 로그 및 약제 사용 대장** — 모든 제어 명령·실행 결과 기록, GAP 인증 양식 PDF 내보내기
9. **사용자 피드백 라벨링 기능** — 판정 정확/오탐 응답 수집 및 재학습 데이터셋 축적
10. **Edge 원격 관리** — OTA 모델 배포, 디바이스 헬스체크, 원격 로그 수집
11. **설치 캘리브레이션 도구** — 컬러 차트 기반 화이트밸런스 보정, ROI 마스크 설정 UI

### 5.2 개발 제외 범위 (Out of Scope) — v1.0

1. **음성 인식 및 음성 명령 제어** — 온실 소음(팬·펌프) 환경에서 인식률 확보가 어렵고, 오인식에 의한 오살포 리스크가 크므로 제외
2. **네이티브 모바일 앱 개발** — v1.0은 반응형 웹 + 카카오 알림톡 링크로 대체. 네이티브 앱은 v2.0 검토
3. **다국어 지원** — 한국어 단일 지원. 수출형 버전(영어·베트남어)은 별도 프로젝트로 분리
4. **클라우드 온라인 학습 / 연합학습(Federated Learning)** — 재학습은 월 1회 오프라인 배치로 수행. 실시간 온라인 학습은 모델 품질 통제 불가로 제외
5. **세분화된 사용자 권한 관리(RBAC)** — v1.0은 관리자/작업자 2단계 고정. 조직 단위 권한 체계는 농업법인 대상 v2.0에서 구현
6. **토마토 외 작물 지원** — 파프리카·오이·딸기 모델은 데이터 확보 후 v1.5 순차 확장
7. **해충 검출 및 방제** — 병해(Disease)만 대상. 해충(Pest)은 별도 트랩 카메라·모델 필요하므로 v2.0 분리
8. **수확량 예측 / 생육 단계 진단** — 병해 감지 목적 외 기능
9. **약제 재고 발주 자동화 및 결제 연동** — 사용량 기록까지만 제공
10. **노지 재배 환경 지원** — 강우·강풍·직사광 변동 대응은 별도 H/W 설계 필요

  1. 파일럿 농가 3개소에서 6개월간 조기 검출 리드타임 **3일 이상 선행**을 실증할 것
  2. 미탐률 3% 이하, 오탐률 5% 이하를 홀드아웃 테스트셋에서 확인한 후 자동 제어 기능을 활성화할 것 (미달 시 알림 전용 모드로 출시)
  3. 초기 12개월 내 **도입 농가 30개소** 확보 계획을 확정할 것. 미달 시 개발비 회수 불가
  4. 스마트팜 보급사업 등 정부 지원(H/W 비용의 50~70% 보조) 연계 시 농가 실부담 CAPEX가 1,650만~2,750만 원으로 낮아져 회수기간이 **5~9개월**로 단축되므로, 지원사업 등록을 우선 추진할 것 (가정)
